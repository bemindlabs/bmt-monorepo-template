# Sprints

This directory contains sprint folders with planning and tracking information.

## Structure

Each sprint has its own directory:

```
sprints/
├── sprint-01/
│   ├── planning.md
│   ├── board.md
│   └── review.md
├── sprint-02/
│   └── ...
```

## Sprint Files

### planning.md

Contains sprint planning details:

- Sprint goal
- Selected backlog items
- Capacity planning
- Commitment

### board.md

Tracks sprint progress:

- To Do
- In Progress
- In Review
- Done

### review.md

Sprint review documentation:

- Completed items
- Demo notes
- Stakeholder feedback

## Usage

Use `/scrum-sprint` to manage sprints:

- Start a new sprint
- View current sprint status
- Close a sprint
