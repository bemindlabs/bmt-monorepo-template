# Product Backlog

This directory contains product backlog items (PBIs) for the project.

## Structure

Each backlog item is stored as a markdown file with the following naming convention:

- `PBI-{number}-{short-description}.md`

## Backlog Item Template

```markdown
# PBI-{number}: {Title}

## Description

{User story or feature description}

## Acceptance Criteria

- [ ] Criterion 1
- [ ] Criterion 2

## Priority

{High | Medium | Low}

## Story Points

{Estimated points}

## Status

{New | Ready | In Sprint | Done}
```

## Usage

Use `/scrum-backlog` to manage backlog items:

- Add new items
- Prioritize existing items
- Move items to sprints
