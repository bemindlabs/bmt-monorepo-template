# Daily Standups

This directory contains daily standup notes.

## Structure

Standup notes are organized by date:

```
standups/
├── 2024-01-15.md
├── 2024-01-16.md
└── ...
```

## Standup Template

Each standup file follows this format:

```markdown
# Standup - {Date}

## {Team Member}

### Yesterday

- What was accomplished

### Today

- What will be worked on

### Blockers

- Any impediments (or "None")
```

## Usage

Use `/scrum-standup` to:

- Record daily standup notes
- View recent standups
- Track blockers across the team
