# Sprint Retrospectives

This directory contains sprint retrospective documents.

## Structure

Retrospectives are named after their sprint:

```
retrospectives/
├── sprint-01-retro.md
├── sprint-02-retro.md
└── ...
```

## Retrospective Template

```markdown
# Sprint {N} Retrospective

**Date:** {Date}
**Participants:** {Team members}

## What Went Well

- Positive item 1
- Positive item 2

## What Could Be Improved

- Improvement area 1
- Improvement area 2

## Action Items

- [ ] Action 1 - Owner: {Name}
- [ ] Action 2 - Owner: {Name}

## Previous Action Items Review

- [x] Completed action from last retro
- [ ] Ongoing action
```

## Usage

Use `/scrum-retro` to:

- Create retrospective documents
- Track action items
- Review past retrospectives
