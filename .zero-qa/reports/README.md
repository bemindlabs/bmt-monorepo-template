# Zero-QA Reports

This directory stores quality assurance reports generated by Zero-QA tools.

## Report Types

### Code Review Reports

- Generated by `/zero-qa-review`
- Stored as `review-{date}-{hash}.md`
- Contains automated code review findings

### Quality Gate Reports

- Generated by `/zero-qa-gate`
- Stored as `gate-{date}-{hash}.md`
- Contains pass/fail status for all quality gates

### Test Coverage Reports

- Generated by test runners
- Coverage summaries and trends

### Security Scan Reports

- Generated by security scanning tools
- Vulnerability findings and remediation

## Report Naming Convention

```
{type}-{YYYY-MM-DD}-{short-hash}.md
```

Examples:

- `review-2024-01-15-abc123.md`
- `gate-2024-01-15-def456.md`

## Retention

- Keep recent reports for trend analysis
- Archive older reports monthly
- Delete reports older than 90 days

## Usage

Reports are automatically generated when running Zero-QA commands.
View reports directly or use `/zero-qa-check` for a summary.
