Auto-generate documentation from code implementation.

Analyze the codebase and generate documentation following project standards.

## Process

1. **Scan Implementation**
   - Find all source files in `apps/`
   - Identify public APIs, functions, classes
   - Extract JSDoc/docstrings/comments

2. **Generate Docs**
   - Create API docs in `docs/api/`
   - Create architecture docs from code structure
   - Update existing docs with new implementations

3. **Output Format**
   Follow naming conventions:
   - `docs/api/<project>-<module>.md`
   - `docs/architecture/<project>-overview.md`

4. **Auto-update README**
   - Update project tables if new modules found
   - Regenerate docs index

