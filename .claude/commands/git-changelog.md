Create a new changelog entry.

Ask for:

1. Version number (e.g., v1.0.0)
2. Type: major | minor | patch
3. Changes summary

Create file at `docs/changelogs/YYYY-MM-DD-<version>.md`:

```markdown
# <Version>

**Release Date:** YYYY-MM-DD
**Type:** Major | Minor | Patch

## Changes

### Added

-

### Changed

-

### Fixed

-

### Removed

-
```

Use today's date and follow Keep a Changelog format.
