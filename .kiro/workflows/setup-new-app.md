# Setup New App Workflow

This workflow guides you through creating a new application in the monorepo.

## Steps

### 1. Create App Directory

Create a new directory under `apps/` with your app name:

```bash
mkdir apps/[app-name]
cd apps/[app-name]
```

### 2. Initialize App Package

Create `package.json` with proper configuration:

```json
{
  "name": "[app-name]",
  "version": "0.1.0",
  "private": true,
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start",
    "lint": "eslint . --ext .ts,.tsx",
    "lint:fix": "eslint . --ext .ts,.tsx --fix",
    "type-check": "tsc --noEmit"
  },
  "dependencies": {
    "next": "^14.0.0",
    "react": "^18.0.0",
    "react-dom": "^18.0.0"
  },
  "devDependencies": {
    "@types/node": "workspace:*",
    "@types/react": "^18.0.0",
    "@types/react-dom": "^18.0.0",
    "typescript": "workspace:*"
  }
}
```

### 3. Create TypeScript Configuration

Create `tsconfig.json`:

```json
{
  "extends": "../../tsconfig.react.json",
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  },
  "include": ["next-env.d.ts", "**/*.ts", "**/*.tsx", ".next/types/**/*.ts"],
  "exclude": ["node_modules"]
}
```

### 4. Create Next.js Configuration

Create `next.config.js`:

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  reactStrictMode: true,
  swcMinify: true,
  transpilePackages: ['@monorepo/ui', '@monorepo/utils'], // Add your packages here
  experimental: {
    turbo: {
      rules: {
        '*.svg': {
          loaders: ['@svgr/webpack'],
          as: '*.js',
        },
      },
    },
  },
};

module.exports = nextConfig;
```

### 5. Create App Structure

```bash
mkdir -p src/app src/components src/lib
touch src/app/layout.tsx src/app/page.tsx
```

### 6. Create Basic App Files

#### src/app/layout.tsx

```typescript
import type { Metadata } from 'next';

export const metadata: Metadata = {
  title: '[App Name]',
  description: 'Generated by create next app',
};

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

#### src/app/page.tsx

```typescript
export default function Home() {
  return (
    <main>
      <h1>Welcome to [App Name]</h1>
      <p>Your new Next.js app is ready!</p>
    </main>
  );
}
```

### 7. Install Dependencies

```bash
pnpm install
```

### 8. Update Turbo Configuration

Add the new app to `turbo.json` if needed for specific configurations.

### 9. Verify Setup

```bash
# Start development server
pnpm dev --filter [app-name]

# Build the app
pnpm build --filter [app-name]
```

## Additional Configurations

### For Express/Node.js Apps

Replace Next.js dependencies with:

```json
{
  "dependencies": {
    "express": "^4.18.0",
    "@types/express": "^4.17.0"
  }
}
```

### For React SPA Apps

Use Vite configuration:

```json
{
  "dependencies": {
    "react": "^18.0.0",
    "react-dom": "^18.0.0",
    "vite": "^5.0.0",
    "@vitejs/plugin-react": "^4.0.0"
  }
}
```
